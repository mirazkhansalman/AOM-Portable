# AOM Portable

**AOM** (Digital Post Office & Training Center) — a portable desktop app for managing training-center students, attendance, fees, receipts, and related records.

One shared `User_Data` folder works across **Mac** and **Windows**, so data stays with the portable folder when you move between machines.

## Platforms

| Platform | Status |
|---|---|
| **macOS** Intel | Available |
| **macOS** Apple Silicon | Available |
| **Windows** portable | Available |

## Highlights

- Student, attendance, and fee management
- Receipts / PDF exports
- Portable folder layout (apps + shared `User_Data`)
- Mac + Windows in one package
- Built for local training-center workflows

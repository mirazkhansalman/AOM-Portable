# AOM Portable v1.1.0

**AOM** (Digital Post Office & Training Center) — a comprehensive portable desktop application for managing vocational and computer training center students, batch routines, daily attendance registers, financial accounts, and official notice broadcasts.

One shared `User_Data` folder works across **Mac** and **Windows**, keeping all center data in sync when moved between machines on a USB drive or local network.

## Key Capabilities (v1.1.0)

- **Student Directory & Lifecycle:** Active, Quarantine, Completed, and Exam-Complete status tracking with advanced sorting (Due Balance, Absences, Admission date).
- **Automated Absence Alerts:** 3-consecutive-absence detection with automatic official email notifications to students.
- **Batch Notice Broadcast:** 1-click overdue student notice dispatch with individualized student fee statements and attendance notices.
- **Daily Roll Call Registry:** Live routine switcher, real-time presence/absence tracking, and automated summaries.
- **Finance & Cashflow:** Dual-entry ledger, receipt slip generation, Sharif Hossain authorized vouchers, and Excel/CSV exports.
- **Isolated Configurator:** Sensitive gateway credentials (SMTP App Passwords, SMS Gateways) isolated in encrypted companion app.
- **Portable Architecture:** Zero external database installation needed; runs locally anywhere.
